## UUID / clip_001 incompatibility fix

**Problem**: The original seed migration used `clip_001`, `clip_002` style IDs while the database schema defines `videos.id` as `uuid` with `gen_random_uuid()` default. This created an incompatibility between the schema (expecting UUID) and seed data (using string IDs like `clip_001`).

**Fix**: Updated seed migration and all mock data to use proper UUID strings (deterministic v5-style) instead of `clip_001` style IDs.
